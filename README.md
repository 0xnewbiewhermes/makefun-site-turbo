A zero-libc freestanding native C static site generator for makefun-site 1.0.0 with runtime AVX2/BMI2/SSE2 dispatch, nibble-LUT SIMD Markdown and JSON streaming, direct-opcode template compilation, and shared card caching.

## Run it

```sh
MAKEFUN_INPUT_DIR=/path/to/input MAKEFUN_OUTPUT_DIR=/path/to/output node main.ts
```
